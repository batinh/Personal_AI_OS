7.  Phải đảm bảo tính kế thừa
8. Language Demarcation Line: Strictly enforce the boundary between Developer-Facing and User-Facing elements to ensure international standard coding while serving local users:
  + ZONE 1 (Developer-Facing - 100% ENGLISH): Source code (functions, variables, classes), database schemas (tables, columns), system logs, git commits, and docstrings.
  + ZONE 2 (User-Facing - VIETNAMESE): AI Persona/Prompts, UI/Frontend text, Telegram/Strava notifications, and actual data records stored in the database.
  + ZONE 3 (Transition): In template files or prompt builders, Python variables/logic must be in English, while the string templates (f-strings) injected into the AI remain in Vietnamese.
