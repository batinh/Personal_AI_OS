recommendations

Scope /plan invocations tighter. The /plan skill averaged 520K tokens per call (9.6% of the week). Before triggering /plan, share the relevant files directly in the prompt rather than letting the planner agent re-explore the codebase — this cuts the per-invocation cache-create cost by ~50%.
Break "yes, implement cả 3"-style prompts into sequential steps. Single broad implementation approvals result in 40+ API call chains that are hard to steer. Splitting "implement A, then B, then C" into three separate messages keeps each chain under 15 calls and makes it easy to course-correct between phases.
Avoid /context-budget near context limit. The single cache break happened when /context-budget was called at 91% context fill, forcing a cold cache re-seed of 126K tokens. Run /context-budget earlier (at ~70% fill) to act on its findings before the window is exhausted.
homunculus project has 10 sessions at 20.8% of tokens but only 10 human messages. This suggests many small automated or exploratory calls. Confirm these are intentional — if they're idle polling loops, adding a longer sleep between iterations would cut costs proportionally.
